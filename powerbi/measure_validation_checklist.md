# Power BI measure validation checklist

This is the third Power BI setup step: apply the versioned TMDL measures and verify that Power BI reproduces the SQL-validated full-dataset metrics.

Do not build report pages yet.

## 1. Apply the TMDL script

After the five tables and four relationships are in place:

1. Open **TMDL view** in Power BI Desktop.
2. Open a new empty TMDL tab.
3. Paste the contents of:

```text
powerbi/TMDLScripts/01_measures.tmdl
```

4. Select **Apply**.
5. Confirm the measures appear under `fact_sales`.

The script uses `createOrReplace`, so rerunning the same version updates the managed measures rather than requiring duplicate manual measures.

## 2. Confirm measure folders

Under `fact_sales`, confirm these display folders exist.

### KPIs

- Net Revenue
- Non-Cancellation Revenue
- Sales Orders
- Units Sold
- Average Order Value
- Active Customers
- Net Revenue per Active Customer

### Cancellations

- Cancellation Invoices
- Total Invoices
- Cancellation Invoice Rate
- Cancellation Value
- Cancellation Units

Do not create alternative copies of these measures in other tables.

## 3. Validate the unfiltered model

Create a temporary table or set of cards with **no report, page, visual or slicer filters**.

The measures must reproduce the values generated by the full PostgreSQL validation run:

| Measure | Expected value |
| --- | ---: |
| Net Revenue | £19,287,250.57 |
| Non-Cancellation Revenue | £20,813,918.43 |
| Sales Orders | 45,336 |
| Units Sold | 11,672,569 |
| Average Order Value | £459.10 |
| Active Customers | 5,881 |
| Net Revenue per Active Customer | £2,841.24 |
| Cancellation Invoices | 8,292 |
| Total Invoices | 53,628 |
| Cancellation Invoice Rate | 15.46% |
| Cancellation Value | £1,526,667.86 |

A small difference caused only by display rounding is acceptable. The underlying measure values must agree with the SQL definitions.

## 4. Validate filter behaviour

After the unfiltered totals match, perform three small checks.

### Date filter

Filter the model to **January-November 2011**.

Confirm:

- Net Revenue: **£8,565,122.90**
- Sales Orders: **19,496**
- Active Customers: **4,174**
- Average Order Value: **£470.97**
- Cancellation Invoice Rate: **14.72%**

### Country filter

Filter `dim_country[country_name]` to **United Kingdom**.

Confirm Net Revenue:

```text
£16,382,583.90
```

### Product-type filter

Filter:

```text
dim_product[product_type] = merchandise
```

Confirm operational entries such as `DOT`, `POST`, `AMAZONFEE` and `BANK CHARGES` disappear from product-level selections.

Do not apply the merchandise filter to whole-business revenue cards. Operational entries remain part of total financial activity.

## 5. Formatting checks

Confirm:

- monetary measures use GBP formatting;
- count measures use whole-number formatting;
- Cancellation Invoice Rate uses percentage formatting with two decimal places;
- negative monetary values remain visibly negative;
- no implicit aggregation is used in place of the versioned measures.

## Stop point

Once these validations pass, save the Power BI file/project.

Do not build the Executive Overview yet. Report-page construction is the next separate task.
